## Project Structure

- `src/uniqueizer/`: Core PIL image uniqueization library
  - `core.py`: `PhotoUniquezer` class with `uniqueze()` entrypoint
  - `entities.py`: Dataclasses for image operations and settings

## Key Files

- `main.py`: Placeholder CLI (not connected to library)
- `pyproject.toml`: Basic package config; no lint/test scripts defined
- `uv.lock`: Lockfile for `uv` package manager
